# Submissions

Each saved person is one row in `volunteer_directory_entries`.

The admin search box matches:

- name
- email
- phone
- address
- selected skills
- other skill
- note

Open a row to see the full address, skills, other skill, and note. Delete removes that person from the list.

The public form still requires a note, and it requires a checked skill or an other skill before it will save.
